# b1tninja-labs portfolio

Plans, roadmap issues and the status site for b1tninja-labs projects.

- **Issues** here are generated by [projecthub](https://github.com/b1tninja-labs/projecthub) from its planning
  database. Text inside a `forge` region of an issue body is overwritten by the sync; text outside it is yours.
- **The site** is built by `tools/build_site.py` and published with GitHub Pages: when projecthub reports a
  change to Project 1 (`repository_dispatch`), hourly as a fallback, and on every push to `main`.
- **`data/`** is not committed. `projecthub site --out data` writes it from Project 1 on every Pages run;
  [DATA.md](DATA.md) is its contract (schema 3). To preview locally, write a data directory and pass it with
  `python tools/build_site.py --out _site --data <dir>`, then serve `_site` over HTTP.
- **`install.json`** holds copy-paste install snippets. Each one was run before it was added.
